# PunBot

This repository contains the final paper and projects from an NLP module focused on pun detection and location.

## Overview

The projects explore a variety of Natural Language Processing techniques to detect and locate puns in text:

- **Pointwise Mutual Information (PMI)** — measures word association strength
- **Cosine Similarity** — compares vector representations of words/phrases
- **Lesk Algorithm** — word sense disambiguation using dictionary definitions
- **Adapted Lesk Algorithm** — an enhanced version using WordNet for better accuracy

## Resources

- WordNet is used as the primary lexical database for sense disambiguation
